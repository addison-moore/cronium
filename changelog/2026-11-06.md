# 2026-11-06

- [2026-11-06] [Fix] **A save that a reverse proxy refuses as too long now says so.** Behind nginx's default `client_max_body_size` of 1 MB, a longer script read `Unexpected token '<', "<html>..." is not valid JSON` in the event form and the JSON import dialog, because the tRPC client parses a response before it looks at the status. Caddy and Traefik gave other parse errors. The app now says `A reverse proxy in front of Cronium refused this request as too long. It should allow up to 10 MB, as Cronium does. In nginx, that's client_max_body_size.`, for any tRPC call and whatever the proxy's 413 looks like. Cronium's own 413 still shows its own message. The MCP stdio bridge says the same, rather than `Cronium /api/mcp returned HTTP 413` and the proxy's page. REST and direct `/api/mcp` callers get the proxy's 413 as before, which the API reference now mentions, and `docs/DEPLOYMENT.md` gives the nginx setting.
