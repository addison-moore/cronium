# 2026-11-09

- [2026-11-09] [Feature] **The event form now offers a check beside the real run for MongoDB Update and Delete, Email and Discord, which changes and sends nothing.** `Count Matches` counts the documents the filter matches, with the real run's own collection and filter revived the same way, and says when only the first would be touched or Upsert would add one. `Check Login` connects and signs in to the mail server exactly as a send would, then leaves before naming a sender or a recipient. It says so when the server never asked for a login, and it doesn't reuse the credential test, which accepts any certificate where the send doesn't. `Check Webhook` asks Discord for the webhook with a GET and passes back only its name, because Discord's answer carries the webhook's token. Each toast says what the check showed and then what it didn't: a login isn't a delivered email, and a count doesn't show the delete would be allowed. The real run still asks first, and its question no longer says there's no test mode. Measured in a production build on throwaway MongoDB and mail servers, with no route out but loopback: no check changed a document or sent a message, and a wrong password or an unknown webhook failed the check as it fails the real run. `countDocuments` refuses `$where`, which a delete accepts, so that check fails and says why. The form now says which it wants, `check`, `simulate` or `run`, and the server refuses a check or a simulation of an action that doesn't declare one, so neither can become a real run. A page loaded before this sends only `isTest`, and still gets the real run its button promised. A check is audited as `CHECKED`. SQL Execute Statement, Slack, Teams, Notion, Trello and Google Sheets get no check: a rollback isn't safe on MySQL, Slack and Teams have no call without an effect, and the rest can't be checked here without real accounts.
- [2026-11-09] [Feature] **The event form now shows what a run from its button returned, under the button.** Pressing `Run Query Now`, `Find Documents Now`, `Aggregate Documents Now` or `Prompt LLM Now` really runs the action, but the rows, the documents and the model's answer only went to the browser console, so someone who paid for a prompt couldn't read the answer. Rows now show as a table, documents as JSON, and an answer as written, with the model, the tokens it used, and a warning when it stopped at Max Tokens. A read can return up to 5 MB, so the form draws the first 100 rows or documents and 200,000 characters at most, cuts a value at 200 characters and a document at 5,000, and says what it left out. The result goes when the credential or action changes, by a choice or through the event's settings, and when the button is pressed again, and one that comes back after the action was changed isn't shown. A parameter edit keeps it and says it's from before, so a paid answer isn't lost to an edit. A simulation shows nothing, since its result is made up, such as Google Sheets' "Product A", and neither does a send or a write, which comes back with little more than the count the toast gives. Each action declares what's shown in `testRun.shows`, which the type requires of a read or a prompt and refuses for the rest. The result no longer goes to the console.
