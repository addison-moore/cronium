# 2026-11-09

- [2026-11-09] [Feature] **The event form now shows what a run from its button returned, under the button.** Pressing `Run Query Now`, `Find Documents Now`, `Aggregate Documents Now` or `Prompt LLM Now` really runs the action, but the rows, the documents and the model's answer only went to the browser console, so someone who paid for a prompt couldn't read the answer. Rows now show as a table, documents as JSON, and an answer as written, with the model, the tokens it used, and a warning when it stopped at Max Tokens. A read can return up to 5 MB, so the form draws the first 100 rows or documents and 200,000 characters at most, cuts a value at 200 characters and a document at 5,000, and says what it left out. The result goes when the credential or action changes, by a choice or through the event's settings, and when the button is pressed again, and one that comes back after the action was changed isn't shown. A parameter edit keeps it and says it's from before, so a paid answer isn't lost to an edit. A simulation shows nothing, since its result is made up, such as Google Sheets' "Product A", and neither does a send or a write, which comes back with little more than the count the toast gives. Each action declares what's shown in `testRun.shows`, which the type requires of a read or a prompt and refuses for the rest. The result no longer goes to the console.
