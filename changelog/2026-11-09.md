- [2026-11-09] [Fix] **Save Workflow on a workflow's Edit page no longer deletes all its nodes and connections.** The page read the workflow after its form had already copied an empty graph, so the canvas opened empty and every save sent no nodes, which the server takes as an instruction: it deleted the workflow's nodes and connections, and the page said the save worked. The canvas now opens on the workflow's nodes and connections, drawn as events with their details, and a save sends the graph only when the canvas changed it. Saving only the details leaves the nodes and connections as they are, so a workflow that's running keeps finding its steps, and canvas changes saved somewhere else since the page loaded stay. The canvas's own buttons (Undo, Undo all changes, Delete selected, and the events list's hide and clear-search buttons) no longer save the form when pressed, here or on New Workflow, where one could create the workflow early. **A workflow already emptied this way can't be recovered from the app:** its nodes and connections were deleted, not hidden, so rebuild it on the canvas or restore it from a database backup.
