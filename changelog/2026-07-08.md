# Changelog - 2026-07-08

- [2026-07-08] [Refactor] Removed the mocked webhooks tRPC router and the orphaned webhook UI components (never mounted on any page); the real outbound `webhookSystem` backend remains dormant for a future UI.
- [2026-07-08] [Feature] Workflow webhook triggers now pass the request payload into workflow execution (available via `cronium.input()`), enforce a 1 MB payload cap, and are rate-limited (60 req/min per key). `WebhookSecurity.checkRateLimit` is now backed by the real Valkey/Redis sliding window instead of always allowing.
- [2026-07-08] [Bug Fix] The email tool plugin's `send-email` action now actually sends via nodemailer (it was a simulation, so automated/conditional email notifications silently did nothing); added `sendEmailDetailed()` returning real delivery info, SSL/timeout support, and comma-separated recipients + `isHtml` handling.
- [2026-07-08] [Bug Fix] Tool "Test Connection" is now real for every supported tool (SMTP verify, Notion/Trello auth calls, Slack/Teams webhook posts, Discord metadata GET, Google tokeninfo) via a shared `connection-tests.ts` helper; removed the always-success mocks in `tools.testConnection`, the per-plugin api-routes, and slack/google-sheets routes; deleted the legacy mock `tools.test` procedure (IntegrationTestPanel repointed).
- [2026-07-08] [Feature] Added a "Send test email" button to the admin SMTP settings backed by a new `admin.sendTestEmail` mutation exercising the saved system SMTP settings.
- [2026-07-08] [Bug Fix] Monitoring dashboard truth-pass: System Health and Recent Activity cards now show real data (`getHealthCheck`/`getActivityFeed`); replaced `Math.random()` CPU with normalized `os.loadavg()`; removed fabricated historical metrics, period comparisons, and the fake external-services check (now reports real cache availability).
- [2026-07-08] [Feature] Admin role permissions are now persisted and enforced: new roles storage (in the live `storage.ts`), `getRoles` moved to `protectedProcedure` (fixes non-admins always receiving FORBIDDEN in `usePermissions`), real `updateRolePermissions` (Admin role protected), idempotent Admin/User/Viewer seeding in `seed-roles.ts` and `bootstrap-seed.cjs`, and server-side enforcement of `monitoring` (page + procedure), `console` (terminal route + new server-gated console page), and `localServerAccess` (local shell branch) via `src/server/permissions.ts`. Removed six zero-consumer admin stub procedures.
- [2026-07-08] [Feature] Google Sheets + OAuth completed: new credential bridge injects a fresh (auto-refreshed) Google access token as `credentials.oauthToken` at all three execution paths (scheduler, manual executeAction, plugin routes); Connect/Disconnect Google Account UI on the Sheets credential card driven by real token status; shared `createProviderFromEnv` OAuth factory; callback now redirects to `/dashboard/tools`; Sheets credential form no longer demands clientId/clientSecret; removed Teams "OAuth2 coming soon" button; documented `OAUTH_*` env vars in env.mjs, `.env.example`, and ENVIRONMENT_VARIABLES.md.
- [2026-07-08] [Bug Fix] Deactivating, deleting, or rescheduling an event now cancels/updates its in-memory scheduled job (was: paused events kept firing until the next tick).
- [2026-07-08] [Feature] Failed jobs are now retried with exponential backoff (up to the event's configured retry count, gated by `scheduledFor`) instead of terminating immediately; exhausted jobs stay FAILED with `attempts`/`lastError` retained. Fixed the orchestrator `ReleaseJob` client endpoint path.
- [2026-07-08] [Refactor] Workflow engine hardening: replaced the 100ms prerequisite busy-poll with event-driven completion notifications (30-min deadline preserved); added a merge-node claim guard to prevent double-execution; workflow execution records now carry the real trigger type (SCHEDULE/WEBHOOK/MANUAL); fixed "every N days" interval scheduling in both the workflow executor and event scheduler (previously fired on fixed weekdays and never fired for N>=8).
- [2026-07-08] [Feature] Orchestrator now sends heartbeat (30s) and metrics (60s) telemetry; the app persists the latest heartbeat/metrics/health snapshots to system_settings (were dropped). Fixed the orchestrator health checker's always-healthy API check to use a real connectivity probe.
- [2026-07-08] [Performance] Added a performance-index SQL migration (FK/composite/claim-query indexes) plus an idempotent apply script.
- [2026-07-08] [Feature] Logs search and start/end date filtering now work (were silently ignored); admin logs are now filtered; removed the unimplemented "archive" bulk operation.
- [2026-07-08] [Feature] Quota usage is now calculated from real per-user counts (events/workflows/webhooks/executions/tool-actions) instead of returning 0; quota-management config now returns real enforcement rules.
- [2026-07-08] [Testing] Added a CI workflow (.github/workflows/ci.yml) running lint/typecheck/test for Node and vet/test/golangci-lint for the three Go modules on push/PR.
- [2026-07-08] [Refactor] Repo hygiene: untracked artifacts/ (87MB of binaries), src/scripts/deprecated/, and root settings.json (all gitignored); relocated test-payload/ to apps/orchestrator/testdata/; removed the unused @sendgrid/mail dependency.
- [2026-07-08] [Documentation] Added open-source governance files (CONTRIBUTING.md, CODE_OF_CONDUCT.md, CHANGELOG.md, GitHub issue/PR templates); fixed docs/GETTING_STARTED.md references to nonexistent packages/scripts/compose files.
- [2026-07-08] [Testing] Extracted job retry backoff into a pure, unit-tested helper (retry-policy.ts) so CI now runs real tests; documented the DB-dependent root tests/ suite and added a test:integration script.
