# 2026-07-22

- [2026-07-22] [Security] Phase 3.6: the orchestrator now fails closed on a plaintext remote Docker endpoint — only a local `unix://`/`npipe://` socket is allowed (no mutual TLS is wired, so a `tcp://` endpoint would expose an unauthenticated Docker API). An operator can override with `CRONIUM_ALLOW_INSECURE_DOCKER_ENDPOINT=true` on a trusted network.

- [2026-07-22] [Security] Phase 3.5: added a CodeQL SAST workflow (TypeScript + Go, `build-mode: none`) on push/PR/weekly-schedule, with actions pinned to SHAs.

- [2026-07-22] [Security] Phase 3.6: excluded secret material (`*.pem`, `*.key`, `known_hosts`, `data/`, `*.bak`, `backups/`) and planning/scratch notes (`_plans`, `_scratch`) from the Docker build context via `.dockerignore`.

- [2026-07-22] [Security] Phase 3.4: aligned the Go toolchain to a single pinned patched version (go 1.25.12) across `go.work`, all three `go.mod` files, CI `setup-go`, and the Docker builders (was 1.22/1.23/1.25 mixed); this clears all reachable Go standard-library vulnerabilities. Added a `govulncheck` gate to CI (per Go module) and a PR `dependency-review` job.

- [2026-07-22] [Security] Phase 3.5: pinned every GitHub Action to a reviewed commit SHA (notably `aquasecurity/trivy-action@master` → v0.36.0 SHA), and made `install.sh` fail closed when no release is discovered instead of pulling a mutable `main`/`latest` image (still allowed under `--no-pull` for local images).

- [2026-07-22] [Security] Phase 3.2: the dormant `POST /api/admin/terminal` local-host command path (arbitrary RCE on the control plane, no UI caller) is now disabled by default. It requires an explicit `CRONIUM_ALLOW_LOCAL_HOST_TERMINAL=true` opt-in and, when enabled, an Admin role + MFA-enabled account, and audits every command. Remote (serverId) SSH execution is unchanged.

- [2026-07-22] [Security] Phase 3.6: production Valkey now runs with `requirepass` (new `VALKEY_PASSWORD`, wired through app/worker via URL, runtime via `RUNTIME_VALKEY_PASSWORD`, and per-job sidecars via new orchestrator `CRONIUM_CONTAINER_RUNTIME_VALKEY_PASSWORD` injection); Postgres/Valkey host port publishes in `infra/docker/docker-compose.yml` bound to loopback. install.sh generates `VALKEY_PASSWORD`; deploy docs/env examples/info-site/install-smoke updated.
