# Changelog - 2026-07-13

- [2026-07-13] [Bug Fix] Tool actions failed at runtime with "Action not found" (e.g. Slack `slack-send-message` on a scheduled event). The tool plugins are `"use client"` modules, so when server code (the scheduler, the OAuth bridge, the `executeAction` tRPC endpoint) imported the plugin objects to read their actions, Next.js handed back client reference proxies with no usable `execute()` — the server action registry came back empty. Fixed by adding a server-safe registry (`src/lib/tools/server-plugin-actions.ts`) that imports each plugin's action definitions directly from their non-client `actions` modules, never through the `"use client"` plugin objects. Extracted email's inline actions into a server-safe `email/actions.ts`, and moved the Google Sheets OAuth config into a server-safe `plugins/oauth-config.ts` (same root cause: the OAuth bridge read `requiresOAuth` off a proxy, so Google Sheets never received its token). Repointed the scheduler executor, the OAuth credential bridge, and the `tools.executeAction` tRPC mutation to the server-safe registry. Verified all 15 actions resolve with real `execute` functions.
- [2026-07-13] [Bug Fix] Silenced two webpack build warnings in `cronium-app`. (1) `Critical dependency: the request of a dependency is an expression` from `@cronium/ui`: `code-viewer.tsx` loaded the Prism line-numbers plugin via `import(variable)`, which webpack can't statically resolve. Restored a static `import("prismjs/plugins/line-numbers/prism-line-numbers")` and added an ambient module declaration (`packages/ui/src/prismjs-plugins.d.ts`) so it still type-checks despite `@types/prismjs` not covering plugin submodules. (2) `Can't resolve 'pg-native'`: added `"pg-native": false` to the client webpack `resolve.fallback`, alongside the existing `util/types`/`dns` stubs — `pg`'s native binding is an optional dependency we don't install, and it's only reached through a server-executed dynamic import inside a `"use client"` tool plugin. Verified: a production build goes from 3 warnings to 0 ("Compiled with warnings" no longer appears).
