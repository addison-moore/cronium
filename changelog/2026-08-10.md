# 2026-08-10

- [2026-08-10] [Fix] Orchestrator SSH pool no longer leaks connections. When two
  jobs targeted the same server concurrently, `Get` dialed a second connection
  and `addConnection` displaced the first in the pool map; `Put` then dropped it
  on the identity check and the idle sweep could not see it, leaking a socket
  and its goroutines per overlap. `Put` is now total — a connection with no
  matching pool entry is closed.
- [2026-08-10] [Fix] `executionCount` is incremented in SQL
  (`storage.recordEventDispatch`) instead of from a value read earlier in
  `dispatchEventJob`. Racing dispatches were losing increments, which let an
  event with `maxExecutions` run past its cap.
- [2026-08-10] [Fix] `advanceWorkflowRun` no longer acquires a second pool
  connection while holding a transaction. Graph reads moved ahead of the
  transaction and telemetry/log writes are flushed after commit, removing a
  self-inflicted deadlock that surfaced as connection timeouts under
  concurrent advances.
- [2026-08-10] [Security] Webhook IP allowlist parses addresses strictly.
  Malformed input (non-numeric, IPv6, wrong octet count, out-of-range or
  zero-padded octets) previously collapsed to `0.0.0.0` and matched a
  `0.0.0.0/x` rule; CIDR prefixes outside 0–32 are also rejected now.
- [2026-08-10] [Fix] In-process worker leases each claimed job against its own
  timeout rather than the batch maximum, so a short job batched with a long one
  is recoverable by the sweeper on its own schedule.
- [2026-08-10] [Chore] Removed ~3,700 lines of dead code: 24 unreferenced
  modules (including `src/app/middleware.ts`, which Next never loaded from that
  path, and the orphaned `useClientEncryption` subsystem) plus the unused
  client-side/compatibility exports in `encryption-service.ts`.
- [2026-08-10] [Docs] Documented that `ConnectionPoolConfig.MaxPerServer` /
  `MinPerServer` are not enforced, and recorded the review in
  `_plans/code-review/PLAN.md`.
- [2026-08-10] [Chore] Raised the app coverage baseline to 32.33% statements /
  28.61% branches after the dead-code removal.
- [2026-08-10] [Fix] De-flaked four security tests that tampered with tokens by
  rewriting trailing base64url characters. A 32-byte HMAC encodes to 43
  characters whose last one carries only 4 significant bits, so the rewrite
  could decode to a byte-identical signature and the "must be rejected"
  assertion failed (~1 run in 1024; it broke CI on be91a68). They now flip a bit
  in the decoded signature/ciphertext and re-encode.
- [2026-08-10] [Chore] Upgraded the GitHub Actions that still target the
  deprecated Node 20 runtime: `actions/checkout` v4.4.0 → v7.0.1,
  `actions/setup-node` v4.4.0 → v7.0.0, `actions/setup-go` v5.6.0 → v7.0.0,
  `actions/upload-artifact` v4.6.2 → v7.0.1, `pnpm/action-setup` v4.3.0 →
  v6.0.10 (the first release that officially supports pnpm 11, which this
  workspace pins). Also SHA-pinned the three floating `@v4` tags in
  npm-publish.yml so every action in the repo is pinned by digest.
