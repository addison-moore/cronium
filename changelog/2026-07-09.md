# Changelog - 2026-07-09

- [2026-07-09] [Bug Fix] `pnpm test` no longer runs the Go suites. `apps/orchestrator` and `apps/runtime` each defined a `test` script identical to their `test:go`, so `turbo test` executed `go test` inside the Node CI job, which has no Go toolchain — `sh: 1: go: not found`. It passed on `ubuntu-latest` only because GitHub-hosted runners ship Go preinstalled, and only one of the two packages failed on the self-hosted runner because turbo replayed a cache hit for the other. Removed the duplicate `test` scripts; `pnpm test` is Node-only, `pnpm test:go` runs Go, and the CI Go job still runs `go vet ./...` + `go test ./...` for all three modules directly. Mirrors the same fix already applied to `lint`.
- [2026-07-09] [Refactor] Rebuilt the marketing site's features section around the three features worth selling. Removed the 8 category pills and per-card badges; removed the "Multiple Script Types", "Encrypted Credentials" and "Detailed Logging" cards; deleted the fabricated "System Status" panel (247 Active Scripts, 99.7% Success Rate, 99.99% Uptime — invented data) and the "Enterprise-Grade Platform" block. Added a workflow-canvas visual, a wall of the 7 real integration logos, and a security block whose every claim is backed by the codebase. The 9 remaining cards are now real links into the docs, making their hover affordance honest; `Features.tsx` dropped an unnecessary `"use client"`, cutting homepage First Load JS from 5.58 kB to 2.68 kB.
- [2026-07-09] [Bug Fix] Fixed a CI workflow that had never actually passed. golangci-lint's `install.sh` greps `checksums.txt` unanchored and also matches the `.sbom.json` row upstream now publishes, so the checksum could never verify (fails on any runner); replaced with a pinned `go install`. The self-hosted runner has no C toolchain, so CI installs with `--ignore-scripts` — lint, typecheck and jest need no native modules. `lint` gained `dependsOn: ["^build"]` (on a fresh checkout `@cronium/ui` was unbuilt, so type-aware rules saw `cn` as an error type). Two Go SSH tests were gated `CI == "" && TEST_SSH_SERVER == ""`, which skipped locally but _ran_ on every CI machine; gated on `TEST_SSH_SERVER` alone.
- [2026-07-09] [Bug Fix] `infra/scripts/lint-go.sh` reported success for its own failures — it ran `golangci-lint run || true` and only failed on a `file.go:L:C:` pattern, so config errors, unknown linters and a missing binary all printed "Go linting passed" and exited 0. Go linting had been a silent no-op. The wrapper now treats exit ≥ 2 as fatal. Migrated both `.golangci.yml` files to golangci-lint v2 (`gosimple` merged into `staticcheck`, `gofmt` is a formatter, `typecheck` is not a linter). Turning linting on reveals ~276 findings in orchestrator and ~58 in runtime, so both Go lint steps are `continue-on-error` until the backlog is cleared.
- [2026-07-09] [Bug Fix] Replaced the retired GitHub Actions build cache (`type=gha`, which returned an HTML error page where buildx expected JSON) with registry cache in GHCR, and bumped `docker/build-push-action` v5 → v6.
- [2026-07-09] [Feature] Added Google Analytics 4 to the marketing site via `next/script` (`afterInteractive`), rendering only in production builds. The measurement ID is overridable with `NEXT_PUBLIC_GA_ID`, which is declared in `turbo.json` so Turborepo does not strip it from the build.
- [2026-07-09] [Security] Bumped `drizzle-orm` 0.44.7 → 0.45.2 (GHSA-gpj5-g38j-94v9, SQL injection via unescaped `sql.identifier()`) and `nodemailer` 6.10.1/7.0.13 → 9.0.3 (GHSA-p6gq-j5cr-w38f, GHSA-rcmh-qjqh-p98v). Also deleted the dead `buildCountQuery`, the only `sql.identifier()` call site in the codebase.
- [2026-07-09] [Security] Upgraded Next.js 15.5.4 → 15.5.20, clearing 21 advisories including a critical RCE in the React flight protocol (GHSA-9qr9-h5gf-34mp) and several App Router middleware bypasses. Vercel was refusing to deploy the vulnerable version.
- [2026-07-09] [Refactor] Updated all in-range dependencies (60 minor, 60 patch, no majors). `pnpm audit` went from 2 critical / 45 high across 28 modules to 0 critical / 0 high. `pg` 8.16.3 → 8.22.0 now imports `util/types`, which the client webpack fallback had to stub.
- [2026-07-09] [Bug Fix] Docker/CI builds: routed the image build to the self-hosted runner (only `ci.yml` had been switched; the ~50-minute `docker-publish.yml` was still on `ubuntu-latest`), dropped `linux/arm64`, and fixed both Go Dockerfiles, which hardcoded `GOARCH=amd64` while buildx was asked for arm64 — the published `linux/arm64` orchestrator image contained an x86-64 binary and could never have run. They now build `FROM --platform=$BUILDPLATFORM` and honour `TARGETARCH`. Pinned pnpm to 10.25.0 in the app image.
- [2026-07-09] [Bug Fix] `turbo.json` now passes `NEXT_PUBLIC_SITE_URL` and the `CONTACT_*` variables through to builds. `NEXT_PUBLIC_*` values are inlined at build time, so an undeclared one is silently stripped and any Vercel override does nothing.
- [2026-07-09] [Testing] The pre-commit hook now rejects a staged `pnpm-lock.yaml` that disagrees with the manifests. Committing a regenerated lockfile without the `package.json` that produced it is invisible locally but breaks every `--frozen-lockfile` install (CI, Docker, Vercel).
