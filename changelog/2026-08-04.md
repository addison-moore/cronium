# 2026-08-04

- [2026-08-04] [Fix] Repaired three breakages from the dependency refresh across `apps/cronium-app`, `apps/cronium-info`, and `packages/ui`. (1) **monaco-editor 0.54 → 0.56 removed `monaco.languages.typescript`** — the TypeScript language service moved to a top-level `monaco.typescript` namespace in 0.55 and the old path is left `undefined`, not shimmed, so `<MonacoEditor>`'s `beforeMount` handler would have thrown a `TypeError` on every mount (it configures compiler options, diagnostics, and the `cronium.*` extra libs there). `packages/ui/src/components/monaco-editor.tsx` now resolves the namespace once from either location and bails out instead of throwing if neither exists, so the editor still mounts if the shape changes again. This affected all four `MonacoEditor` call sites in the app and was invisible to `build`/`test` because the component is mocked out in the Jest suites. (2) The same bump made `@monaco-editor/react@4.7.0`'s exported `Monaco` type unresolvable — it aliases a deep subpath import (`monaco-editor/esm/vs/editor/editor.api`) that 0.56's new `exports` map no longer maps to a `.d.ts`, silently degrading the type to `any` under `skipLibCheck` and failing type-aware lint with 24 `no-unsafe-*` errors. Replaced with local structural types for the members we actually use. (3) `hover.enabled` became `"on" | "off" | "onKeyboardModifier"` in 0.56, which broke the `@cronium/ui` d.ts build and cascaded into 975 phantom type errors in `cronium-app` (unbuilt UI types). (4) **@types/node 24 → 26** split `NodeJS.BufferSource` from the DOM `BufferSource`, so the `as BufferSource` cast on the Node-crypto `deriveKey` path in `src/lib/encryption-service.ts` no longer type-checked; the cast was redundant and was dropped (the browser-global counterpart in `useClientEncryption.ts` is unaffected). Verified: workspace `typecheck`, `lint`, `build`, and `test` all green; Node 22 across CI, Dockerfile, and local satisfies the raised engine floors from nanoid 6 (`^22 || ^24 || >=26`), openai 7, and @testing-library/jest-dom 7 (`>=22`).
